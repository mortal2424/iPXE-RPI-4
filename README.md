# Pi Fleet

Панель для Raspberry Pi 4 в локальной сети. Сохраняет список устройств, образ ОС и желаемый порядок загрузки. Доступность проверяет по SSH. Изменения EEPROM, установка ОС и сбор метрик из панели пока не подключены.

Скопируйте `.env.example` в `.env`, укажите адреса и пути, создайте каталог состояния с владельцем UID 10001 и запустите `docker compose up -d --build` на Linux. Панель слушает указанный LAN-адрес на порту 80. Доступ рассчитан на доверенную локальную сеть.

Сервис загрузки использует порт 8083 и обслуживает только IP тестовой Pi. В `FLEET_BOOT_FILES/boot` можно поместить подписанные `boot.img` и `boot.sig`. Скрипт `build-probe.sh` собирает диагностический RAM-образ из файлов загрузочного раздела Pi, BusyBox и его библиотек. Для HTTP-загрузки понадобится соответствующий открытый ключ в EEPROM. Закрытый ключ храните вне репозитория и контейнеров.
